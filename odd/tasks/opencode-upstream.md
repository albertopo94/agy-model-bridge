# Feature Tasks: OpenCode CLI as Upstream Provider

Bridge upstreams Antigravity (Cloud Code Assist) and Cursor (agent CLI); add OpenCode CLI as a
third upstream exposing its **free-tier** models (`opencode/*`) with ACP pre-warmed execution,
source-tagged display names, clean region/auth error mapping, and an OpenCode tab on the dashboard.

## Specs

- **S1 — Upstream parity.** User (verbatim): "asi como cogemos los modelos de antigravity y de Cursor quiero que hagamos lo mismo con los de opencode (cli)". OpenCode must be served like the other upstreams: discoverable in `GET /v1/models`, routable through `POST /v1/chat/completions` and `POST /v1/messages`, executed locally via the `opencode` binary, zero external dependencies (Python 3 stdlib only).
- **S2 — Free tier only.** User decision (verbatim): "solo los gratuitos". Expose only OpenCode free-tier models (ids ending `-free` under the `opencode/` provider, e.g. `opencode/pulse-alpha-free`). No `google/*`, no `openai/*`, no other providers — their credentials are account-external and `google/*` would duplicate the Antigravity pool.
- **S3 — Source tag in display names.** User (verbatim): "que quede identificada la fuente como hacemos con los otros que les ponemos al final algo asi como \"[agy]\"". Display names get a trailing source tag like the Cursor tag: `Pulse Alpha Free [OpenCode]`, `DeepSeek V4.1 Flash Free [OpenCode]`, etc. `owned_by` = `opencode`.
- **S4 — ACP pre-warmed execution.** User decision (verbatim): "ACP precalentado (igual que Cursor)". Keep a warm `opencode acp` JSON-RPC 2.0 process over stdio (handshake: `initialize` → `session/new`; per-prompt `session/set_model` + `session/prompt`; stream `session/update` → `agent_message_chunk` → `text`). Fallback to `opencode run -m <model> --format json --pure` subprocess when ACP is unavailable/disabled, mirroring `CursorBackend`'s ACP→CLI fallback.
- **S5 — Clean region/availability errors.** Observed upstream errors (evidence 2026-11-03, machine region): ACP `session/prompt` error `code -32603, message "Internal error: This model is not available in your country", data.errorName "APIError"`; `opencode run` `403 RegionError "This model is not available in your country"` (`cf-placement: remote-IAD`); other free models time out with zero output (user-visible: `Error: Provider error (Qwen3.8 Flash Next (AMD Radeon Cloud)): stream interrupted`). The bridge must detect these and return a readable error naming the model and the cause (region/availability or authentication), never a bare interrupted stream.
- **S6 — Dashboard OpenCode tab.** User decision (verbatim): "Sí, con pestaña OpenCode". Quota panel gains an OpenCode tab next to Antigravity/Cursor. Upstream exposes no provider quota, so the tab must not fake limit bars: it shows OpenCode availability (binary present, version, count of free models discovered) and local usage summary when `opencode stats` is available, with an honest note. Strings in EN and ES (i18n contract).
- **S7 — Test and release discipline (AGENTS.md).** Test-first (RED→GREEN) for new behavior plus one regression test per existing command sharing changed code; `python3 -m unittest discover -s tests -v` 100% green; README test count synced; SemVer MINOR bump (`0.30.1 → 0.31.0`) synchronized in `bridge/__init__.py` and `pyproject.toml`; conventional commits, no AI attribution.
